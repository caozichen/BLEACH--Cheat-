# 新电脑使用验证

日期：2026-11-10。被验证的下载基线为仓库提交 `af78e6562070a521c6fcc972422e078eb5101133`。后续 README 补充不会改变本次验证的金手指和运行脚本。

## 结论与前置条件

可以迁移到新的 Windows 10/11 x64 电脑。只使用金手指时无需 Git、Node.js、Python 或 PowerShell 7；但新电脑须自行准备 PPSSPP v1.19.3 x64 和 UCAS40234 / 1.00 的游戏镜像。仓库不包含模拟器程序、游戏镜像或个人存档。

手工安装步骤在 [README 靠前的新电脑教程](../README.md#新电脑首次使用一步一步安装)。安装文件是 `cheats/UCAS40234.ini`，目标为模拟器实际记忆棒中的 `PSP/Cheats/UCAS40234.ini`。

自动安装脚本需要 PowerShell 7；重建配置需要 Node.js；运行分析工具需要 Python 和可选的 Capstone。`archive/` 中保留了历史本机路径，不作为新电脑的日常运行入口。

## 验证边界

本次使用当前电脑上的新下载目录、独立进程和模拟的新用户路径，没有实际使用另一台物理电脑，也没有在本轮重新启动游戏。PPSSPP 主机进程的 PID、宿主内存地址没有固化在正式金手指中；游戏角色通过 PSP 内部的静态指针定位，换电脑不需要继承旧 PID 或宿主地址。

此前运行读回确认了六项攻击加成 3100、当前/最大 HP 99999、防御 9999 和 SP 999；打怪与受击的全面实战对比仍未完成。其他地区游戏、续作、修改版及 PPSSPP 版本不在已验证范围内。
