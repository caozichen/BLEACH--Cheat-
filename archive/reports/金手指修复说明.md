# 《死神 灵魂嘉年华》金手指修复说明

适用环境：PPSSPP v1.19.3，游戏 UCAS40234 / 1.00。日期：2026-10-31。

实际使用文件：`C:\Users\曹梓晨\Documents\PPSSPP\PSP\Cheats\UCAS40234.ini`。

## 已提供的选项

| 选项 | 默认状态 | 用途 |
|---|---|---|
| 攻击倍率32倍 | 开启 | 修复原攻击代码，写入六项攻击属性加成 |
| 攻击倍率16倍、64倍 | 关闭 | 攻击倍率选项只开启一个 |
| 攻击倍率1倍 | 关闭 | 将上述六项加成清零；会覆盖同字段的正常装备/技能加成 |
| 锁HP9999 | 开启 | 保留原来的目标值，改用32位写入，避免切换高HP时残留高位 |
| 锁HP99999 | 关闭 | 同时锁定当前HP和最大HP为99999；先关闭锁HP9999 |
| 防御力9999 | 关闭 | 提高当前玩家防御，降低按防御结算的普通物理伤害 |

打开游戏后，在暂停菜单的“金手指”中选择。攻击倍率只开一项，两个锁HP选项也只开一项。原“锁SP”继续保持原开关。

关闭选项会停止后续写入，已经写入的值可能继续保留。需要恢复正常属性时，关闭相关选项、重新启动游戏并从普通游戏存档进入；即时存档会保留存档当时的内存数值。

## 三个结论

**HP能够超过9999。** 游戏HP实际按32位读写，旧金手指只写了16位。本次测试副本中的当前HP、最大HP均已读回为99999。99999是本次验证值，不代表所有更大数值都已验证；界面能否完整显示五位数也未单独验证。

**攻击倍率能够超过16倍。** 游戏在这里使用 `倍率 = 1 + 加成值 / 100`。16倍写1500，32倍写3100，64倍写6300。这里没有16倍限制。但后续单次伤害通常封顶9999，特定类型/状态使用999999上限，所以更高倍率未必继续增加最终显示伤害。原代码的 `FFFF` 对应65535的加成值，即656.35倍，并不是65535倍。

**降低受伤有防御选项。** 新增的防御力9999只写当前玩家属性。普通物理伤害路径会从攻击侧的计算值中扣除防御计算值，因此提高防御可以减轻这类攻击；这不是固定百分比减伤，对绕过防御的灵压、固定伤害或特殊攻击不能作同样保证。锁HP属于周期补血，单次致死攻击仍可能在下次补血之前结算。

## 修复和验证依据

原攻击代码最后一段声明了多行指针数据，实际提供的行数不足，PPSSPP v1.19.3会跳过该段。修复版改为通过已核实的玩家静态指针，分别对六个32位加成字段直接写入。

- 玩家指针：`*(0x08F1D46C)`；每个场景的指针值可能不同。
- 六项攻击加成偏移：`+0x918 / 91C / 920 / 924 / 928 / 92C`。
- 当前HP：`+0x798`；最大HP：`+0x8E8`；防御：`+0x8F4`。
- 攻击加成计算见游戏代码 `0x08833D6C–0x08833DD8`。
- 普通物理攻击及防御计算见 `0x08833E94–0x08833F30`；防御路径读取角色的防御字段并乘2.5。
- 伤害上限结算见 `0x08834004–0x0883408C`。

验证使用独立的PPSSPP副本和复制的关卡即时存档，没有操作原模拟器的存档。只读检查实际运行内存，得到：

```text
六项攻击加成 = [3100, 3100, 3100, 3100, 3100, 3100]，对应32倍
当前HP = 99999
最大HP = 99999
防御力 = 9999
SP = 999
```

运行读回记录：`combined-runtime-validation.json`。这确认了金手指在该模拟器/游戏版本中能执行、能写到当前角色；没有进行打怪及受击前后的实战伤害对比。
