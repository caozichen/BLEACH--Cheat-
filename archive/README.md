# 历史工作文件

此目录完整保留 2026-10-31 修复时实际使用的脚本和报告，便于对照过程。当前可复用入口在根目录 `scripts/`，使用方法见根目录 README。

历史脚本中的本机绝对路径、测试 PID 文件、即时存档与模拟器副本依赖没有改写，不能在新电脑直接照抄运行。`repair-cheats.mjs` 是当时的一次性生成脚本，要求输入仍为未修复版本；正式文件安装后再次运行它会因找不到旧攻击段而退出。

`runtime-check.mjs` 是未成功连接的 WebSocket 调试尝试，端口 26183 的连接超时，因此没有用它确认金手指效果。最终运行验证采用 `read_test_memory.py` 的 Windows 只读进程内存检查，原记录在 `evidence/`。

历史《检查结果》描述修复前的 27 项金手指，报告中“攻击段无效”是修复前状态；原备用 SP、3 倍速度段仍有指针行数问题。本次正式生成器只修复攻击段及锁 HP 写入宽度，并新增高 HP、普通物理防御选项。
